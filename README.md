# chatterbox

Chatterbox is an F#, standards-compliant implementation of a WebSub hub inspired by - and intended to be a drop-in replacement for - [WebSubHub](https://websubhub.com/), the Elixir reference implementation.

WebSub (formerly known as PubSubHubbub) is an open W3C Recommendation protocol that enables real-time, event-driven, publish-subscribe communication over HTTP.
